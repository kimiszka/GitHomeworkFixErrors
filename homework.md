## 2. What is JavaScript?

## 3. What three problems does Git & GitHub solve?

Version control: tracks every change to your code, so you can see what changed, when, and why, and go back to an earlier version if something breaks.

Collaboration: Github allows multiple people to work on the same project at once without overwriting each other's work. 

Backup and storage: Github stores repositories online, so codes are safe in the event your computer fails. It's easy to share, review, and publish projects.

## 4. What happens when you `fork` a repository?

You make your own copy of someone else's repository on Github, under your account. 

## 5. What happens when you clone a repository?

Downloads a repository from GitHub to your computer, so you can work on it locally.

## 6. What is a Pull Request?

Pull Request: A request to add your changes to a project. You propose your changes, others review them, and if approved, they get merged into the main code.
